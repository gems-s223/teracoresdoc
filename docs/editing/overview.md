# Editing the Model

Once a project is open, most day-to-day modeling work happens across a few dedicated editors, each of which keeps the underlying model files consistent for you:

- [Document Editor](../document-editor.md) — direct access to the model's underlying JSON/YAML deck files, for cases the other editors don't cover.
- [3D Viewer](../3d-viewer.md) — view, color, slice, and inspect the mesh in 3D.
- [2D Layer View & Cross Sections](../layer-and-sections.md) — flat single-layer and vertical cross-section views of the mesh.
- [Surface Networks](../surface-networks.md) — model the above-ground gathering system that connects wells to generation units.
- [Sources](sources.md) — manage the model's production/injection sources.
- [Wells](wells.md) — manage the model's wells and their trajectories.

Start with the dedicated editor for what you're working on; reach for the Document Editor only when you need to inspect or hand-edit something at the raw deck level.
