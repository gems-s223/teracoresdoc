# 2D Layer View & Cross Sections

Next to the 3D Viewer tab, the **View** page has two more tabs for looking at the model a different way:

- **2D Layer** — a flat, top-down plot of a single mesh layer at a time, using the same Cell colors/colormap settings as the [3D Viewer](3d-viewer.md). Good for quickly scanning one layer without rotating a 3D camera.
- **Section** — a vertical cross-section through the mesh, useful for inspecting rock types, MINC zoning, or results with depth.

Both share coloring, wiremesh, and results-time state with the 3D Viewer, so switching tabs doesn't lose your place.
