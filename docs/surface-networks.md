# Surface Networks

The **Surface Networks** page (its own Navigation tile) models the above-ground gathering system — pipes, separators, and other facilities that connect wells to generation units — separately from the reservoir mesh. It has three tabs:

- **Config** — define generation units and how they connect to wells/sources.
- **Diagram** — a node-and-wire editor for laying out the network visually (which unit connects to which well, etc.).
- **Results** — once a simulation has produced results, a per-unit results dashboard (pick a **Phase**, and for Future Scenarios a **Scenario**, plus a **Unit**) with an option to export the shown results to Excel.

Surface network configuration is stored per-project (not per-phase), so it doesn't need a specific phase/edit mode to be active before you can work on it.
